Proposed contract: one canonical triage module

      

        
triageFailure(evidence, operationVersion)
Route through AIDE only, accept canonical function set + self-reported confidence, apply >90% block / ≤90% hold, pin operation-version, emit content-minimized audit.

        
applyOwnerDecision(requestId, decision)
First authenticated owner decision wins (resume/stop/rollback), exact function containment, no prohibited Capability Grant, cleanup on 24h expiry.
