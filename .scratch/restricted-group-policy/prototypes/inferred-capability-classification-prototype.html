Inferred Capability Classification contract

      

        
InferCapabilityDescriptor(toolSchema, description, manifest, sourceEvidence)
Analyzes schema parameters, description text, manifest permissions, and source code to derive action/resource/data/effect/target/authority fields. Schema evidence always wins over prose.

        
requireOwnerApproval(inferredDescriptor, groupIdentity)
Every inferred proposal requires explicit owner approval before execution. Approval binds implementation fingerprint and group identity.

        
invalidateOnFingerprintChange(oldFingerprint, newFingerprint)
Any change to source code, version, or schema invalidates prior approval. Execution blocked until re-approval.

        
failClosedOnAmbiguity(ambiguousFields)
When effect classification cannot be determined with confidence, the operation is blocked (not auto-classified as safe).
