# Key Event #1 — Slide-table content (final candidate)

## Key Event

AP-IMS / AP-DS vs. Modem Partition and Deep Dive

## What was discussed and what was decided

- The deep dive covered AP/Modem domain-selection partition, emergency-call flow, IMS control, PDN establishment, network search, EPSFB, MSPM and MIPC/HAL mapping.
- For the Domain Selection partition, P26 selected a hybrid AP/Modem architecture. The related interface definition and call flow were adapted accordingly.
- The workshop covered multiple topics; the hybrid-architecture conclusion applies only to the Domain Selection partition. Other topics retained their own decisions and follow-up items.

## Lesson

- For cross-layer architecture decisions, align the partition, interface, scenario call flow, validation boundary and follow-up owner as one decision package.
- Do not treat an agreed architecture direction as complete until the interface, test responsibility and open-item ownership are documented.
