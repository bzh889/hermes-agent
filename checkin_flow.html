術語對照表

CI

Code Integration
基本編譯驗證 — 確保代碼能編譯通過、不破 build。CI-0 = 最基本 sanity

CI-MTBF

Mean Time Between Failures (for Check-in)
穩定性測試 — 在目標裝置跑 ≥1 小時，確認無 crash/重啟。分 risk level 1~5
有效期 7 天

EWSP

Early Window Service Pack
二進位比對 — bin 檔跟基線比對，Non-target 必須 No different。分 Case1(MCU)/Case3(DSP)/Case5(SWARM bypass)
有效期 7 天

GEWSP

Generic EWSP
= EWSP ✅ + CI-MTBF ✅ 合驗證。Wiki 原文：「Need to pass GEWSP (EWSP/CI-MTBF)」

CIA / CIA2

Check-In Approval / CIA2
審批系統 — CIA 舊版自動審批；CIA2 新版支援 auto + manual。Auto條件：Jira Approved + CR ID 已填
CIA2 Manual 有效期 3 個工作天

MOS

Modem Option Switch
開關管理平台 — 控制 MCF 的 enable/disable，改動 = 影響 SQC load = 必須走 Feature Flow

MCF

Modem Compile Feature
編譯特性開關 — 透過 MOS 管理，決定哪些功能模組被編入 binary

SBP

Subscriber Profile
客戶設定檔 — IMS/SIP 客製化配置 (sbp_id.def, sbp_nvram_vdm_config, ims_config folder)
重要備註
⏱ 效期限制：CI-EWSP 7天 / CI-MTBF 7天 / CIA2 Manual 3個工作天。逾期必須重測或重新申請。

🚫 MCF 規則：修改 MCF（在 MOS 上 enable/disable）影響 SQC 負載 → 禁止走 Non-target 通道，必須走 Feature Check-in Flow 申請 FCIA。

📝 CR Note 格式：Bug fix 需加 [CI-MTBF_PASS][Branch Name]；Non-target 需加 [CL#][NON-TARGET_PASS][CASEx][Branch]。

⚠️ Risk Level ≥ 4：需提前驗證，緊急情況聯繫 func. team 或 PSI (SC/Ralf/Yajyun) 支援。
